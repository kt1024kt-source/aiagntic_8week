# 2026 부산대학교 교직원 직무연수 포털 (PNU HRD Catalog)

배움과 혁신으로 함께 도약하는 효원인을 위한 2026년도 부산대학교 교직원 직무연수 안내 웹사이트입니다.  
공개된 구글 스프레드시트의 데이터를 브라우저에서 실시간으로 불러와 동적으로 렌더링합니다.

---

## 📌 주요 기능

### 1. 메인 페이지 (`index.html`)
- **실시간 통계 KPI 대시보드**: 총 개설 과정 수(32개), 법정의무교육(6개), AI·데이터 역량(4개) 등 실시간 집계
- **스마트 검색**: 과정명, 담당부서, 키워드 실시간 텍스트 검색 및 초기화
- **다중 필터링**: 
  - 10개 분야별 가로 스크롤 탭 (카테고리별 건수 뱃지)
  - 이수구분(필수/권장/선택) 필터
  - 교육방식(온라인/집합/혼합) 필터
  - 수강대상(전직원/실무자/관리자) 필터
- **정렬 기능**: 과정코드순, 교육시간 많은순/적은순, 과정명 가나다순
- **카드 뷰 그리드**: 직관적인 뱃지, 일정, 교육시간, 담당부서 안내 및 상세페이지 연결

### 2. 상세 페이지 (`detail.html`)
- **URL 파라미터 연동**: `detail.html?code=PNU-2026-XXX`
- **상세 커리큘럼 및 학습목표**: 넘버링 스텝 모듈 및 체크리스트 구조화
- **우측 스티키 사이드바**:
  - 수강신청 바로가기 외부 링크 (`https://hrd.pusan.ac.kr/...`)
  - 핵심 정보 요약 테이블 및 담당부서 전화 바로걸기(`tel:`)
  - URL 클립보드 복사 공유 기능
- **연계 추천 연수**: 동일 분야의 다른 연수 과정 2~3개 추천
